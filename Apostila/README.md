# Apostila — Páginas 67 e 68

Atividade de consolidação do aprendizado da apostila.

## Conteúdo
- Preparação e importação de dados
- Criação da coluna de faturamento
- Verificação e tratamento de valores ausentes
- Análise exploratória e estatísticas
- Faturamento por loja
- Ticket médio
- Produtos mais vendidos
- Análise mensal
- Visualizações com Matplotlib e Seaborn
- Gráfico de barras
- Gráfico de linhas
- Gráfico de pizza
- Gráfico de dispersão
- Boxplot
- Heatmap de correlação
- Layout com múltiplos gráficos
- Exportação e comentários analíticos

## Arquivos
- painel_vendas.ipynb — atividade completa
- vendas.csv — base de dados utilizada
- resumo_analitico.csv — principais resultados

Abra o notebook no Google Colab e execute as células para gerar os gráficos na pasta `graficos/`.
